# Bluff & Babel

A Flutter language-learning game with a bluff-vs-truth mechanic.

## Preview (UI flow)

1. Pick language theme (Spanish, Swahili, French, German, Japanese).
2. See immersive background + themed card.
3. Choose between:
   - **Truth** (safer points)
   - **Bluff** (riskier, higher reward if correct)
4. Get animated feedback (green bounce/glow or red shake).
5. Continue rounds while building streak and multiplier.

## Run locally

```bash
flutter pub get
flutter run
```
